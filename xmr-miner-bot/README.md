# ⛏ Бот-майнер Monero (XMR)

Telegram-бот управляет настоящим майнером [XMRig](https://github.com/xmrig/xmrig)
на **вашем** компьютере: запуск и остановка по кнопке, хешрейт, принятые shares,
баланс в пуле. Монеты идут на ваш кошелёк. Управлять может только `ADMIN_ID`.

## Установка

```bash
cd xmr-miner-bot
pip install -r requirements.txt
./install_xmrig.sh          # скачает официальный XMRig в ./xmrig
cp .env.example .env        # впишите BOT_TOKEN, ADMIN_ID, WALLET
python bot.py
```

Кошелёк Monero можно создать в Cake Wallet, Feather или официальном GUI-кошельке.
Ваш Telegram id подскажет @userinfobot.

## Честно про доход

Обычный процессор даёт 1–15 kH/s, это центы в день, и электричество часто
обходится дороже. Пул SupportXMR выплачивает от 0.1 XMR. На арендованных VPS майнинг
обычно запрещён правилами хостинга. Майните только на своём железе.
