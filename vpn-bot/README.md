# 🛡 Aurora VPN: бот для продажи подписки

Telegram-бот, который продаёт доступ к VPN за **Telegram Stars**. Карта, банк и платёжный провайдер не нужны: оплата идёт внутри Telegram.

> Сейчас бот работает в **демо-режиме**: VPN-сервер ещё не подключён, поэтому вместо настоящих ключей он выдаёт ключи с пометкой DEMO. Весь путь покупки при этом работает по-настоящему. Сервер подключается в файле `vpn.py`.

## Что умеет
- 🚀 **Тарифы** на 1, 3, 6 и 12 месяцев со скидками, оплата звёздами прямо в чате.
- 🎁 **Пробный период** (по умолчанию 1 день, один раз на человека).
- 🔑 **Ключ и QR-код** после оплаты, копирование одним нажатием.
- 📲 **Инструкции** для Android, iPhone, Windows и macOS.
- 👥 **Рефералка**: +7 дней за каждого друга, который оплатил подписку.
- 🎟 **Промокоды** с ограничением по числу активаций.
- ⏳ **Напоминание** за сутки до конца подписки и автоматическое отключение после.
- 🛠 **Админка**: статистика и выручка, рассылка, выдача дней, промокоды, возврат звёзд.
- 📄 Команды `/terms` и `/paysupport`, которые Telegram требует от ботов с оплатой.

## Запуск
1. Создай бота у **@BotFather** (`/newbot`) и получи токен.
2. Узнай свой Telegram ID у **@userinfobot**: он нужен для админки.
3. Скопируй `.env.example` в `.env` и заполни. Токен пиши **только в этот файл**: никому его не отправляй и не выкладывай на GitHub (файл `.env` уже в `.gitignore`).
4. Установи и запусти:

```bash
pip install -r requirements.txt
python bot.py
```

Для постоянной работы бота держи его на том же VPS, где будет VPN. Для теста подойдёт и Termux на Android (`pkg install python python-pillow`, затем шаги выше).

## Настройка
| Что | Где |
|---|---|
| Название, слоган, поддержка, пробный период, бонус за друга | `.env` |
| Цены и сроки тарифов, список преимуществ | `config.py` → `PLANS`, `FEATURES` |
| Баннеры разделов и аватарка | папка `banners/`, пересоздаются командой `python make_banner.py` после смены названия |

В `FEATURES` пиши только правду про свой сервер: скорость, страны и так далее.

## Оформление
- Чёрно-золотой стиль: у каждого раздела свой баннер, а после оплаты появляется экран «Добро пожаловать» с конфетти.
- При запуске бот сам ставит себе имя (`BRAND`), описание, которое видно до /start, и меню команд. Отключить это можно через `SET_PROFILE=0`.
- Аватарку бот поставить себе не может: возьми `banners/avatar.jpg` и загрузи её в @BotFather командой `/setuserpic`.

## Команды админа
- `/admin`: статистика, выручка и рассылка
- `/give <id> <дней>`: начислить дни пользователю
- `/addpromo <КОД> <дней> <активаций>`: создать промокод
- `/refund <charge_id>`: вернуть звёзды (charge_id приходит в уведомлении об оплате)

## Как подключить настоящий VPN
В `vpn.py` нужен класс с двумя методами: `issue()` создаёт или продлевает доступ и возвращает ключ, `revoke()` отключает доступ. Затем в `get_provider()` демо-класс меняется на новый. Остальной код бота трогать не нужно.

## Важно
Звёзды выводятся через Fragment (в TON), и для этого есть условия Telegram. В России реклама VPN запрещена, а продажа доступа несёт юридические риски для продавца. Прежде чем брать деньги с людей, разберись в этом вместе со взрослым.
