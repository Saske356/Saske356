# 🛡 Aurora VPN: бот для продажи подписки

Telegram-бот, который продаёт доступ к VPN за **Telegram Stars**. Карта, банк и платёжный провайдер не нужны: оплата идёт внутри Telegram.

> Без сервера бот работает в **демо-режиме** и выдаёт ключи с пометкой DEMO, а весь путь покупки при этом работает по-настоящему. Настоящий VPN ставится на сервер одной командой, см. «Установка на сервер».

## Что умеет
- 🚀 **Тарифы** на 1, 3, 6 и 12 месяцев со скидками, оплата звёздами прямо в чате.
- 📱 **Устройства**: при покупке гость выбирает 1, 2, 3 или 5 устройств, цена растёт по множителю (`DEVICE_OPTIONS` в `config.py`).
- 🗝 **Мои подписки**: у одного гостя может быть несколько подписок, у каждой свой ключ, срок и название, которое можно поменять.
- 🔁 **Автопродление** для тарифа на месяц: встроенные подписки Telegram Stars, звёзды списываются сами раз в 30 дней. Отключается кнопкой в боте или в настройках Telegram.
- 🎀 **Подарки**: гость оплачивает подписку для друга и получает ссылку, по которой подарок активируется в один шаг.
- 🎁 **Пробный период** (по умолчанию 1 день, один раз на человека).
- 👥 **Рефералка**: +3 дня за каждого нового друга, который запустил бота по ссылке. Можно переключить на «бонус после оплаты друга» (`REF_ON_JOIN=0`).
- 📣 **Бонус за подписку на канал**: +1 день один раз. Задаётся через `CHANNEL`, бот должен быть админом канала, чтобы проверять подписку.
- 🛎 **Консьерж в боте**: гость пишет вопрос, тебе приходит тикет, ты отвечаешь ответом на сообщение, и бот пересылает ответ гостю.
- 🎟 **Промокоды** с ограничением по числу активаций.
- ⏳ **Напоминание** за сутки до конца подписки (кроме подписок с автопродлением) и автоматическое отключение после.
- ⚡ **Два способа подключения в одной подписке**: VLESS Reality по TCP (надёжный) и Hysteria2 по UDP (быстрый, с низким пингом на плохой связи). Приложение с автовыбором само берёт тот, что быстрее.
- 📱 **Лимит устройств проверяется на сервере**: если к подписке подключено больше устройств, чем оплачено, гость получает предупреждение, а при продолжении подписка отключается на 30 минут.
- 📊 **Трафик**: виден гостю в подписке и в приложении VPN, админу в `/traffic`.
- 🎯 **Возврат гостей**: напоминание за 3 часа до конца пробного периода, скидка на первую покупку после него, персональные скидки через 3 и 7 дней после окончания подписки.
- 📈 **Воронка продаж** в `/funnel`: сколько гостей берут пробный, платят и продлевают.
- 🛠 **Админка**: статистика и выручка, рассылка в фоне, выдача дней, промокоды, платежи с возвратом в одну кнопку.
- 📄 Команды `/terms` и `/paysupport`, которые Telegram требует от ботов с оплатой.

## Запуск
1. Создай бота у **@BotFather** (`/newbot`) и получи токен.
2. Узнай свой Telegram ID у **@userinfobot**: он нужен для админки.
3. Скопируй `.env.example` в `.env` и заполни. Токен пиши **только в этот файл**: никому его не отправляй и не выкладывай на GitHub (файл `.env` уже в `.gitignore`).
4. Установи и запусти:

```bash
pip install -r requirements.txt
python bot.py
```

Для постоянной работы бота держи его на том же VPS, где будет VPN. Для теста подойдёт и Termux на Android (`pkg install python python-pillow`, затем шаги выше).

| Что | Где |

В `FEATURES` пиши только правду про свой сервер: скорость, страны и так далее.

## Оформление
- Чёрно-золотой стиль: у каждого раздела свой баннер, а после оплаты появляется экран «Добро пожаловать» с конфетти.
- При запуске бот сам ставит себе имя (`BRAND`), описание, которое видно до /start, и меню команд. Отключить это можно через `SET_PROFILE=0`.
- Аватарку бот поставить себе не может: возьми `banners/avatar.jpg` и загрузи её в @BotFather командой `/setuserpic`.

## Мини-приложение
В папке `docs/` лежит мини-приложение: оно открывается прямо внутри Telegram. В нём статус подписки, тарифы с оплатой, ключ с QR-кодом, инструкции и приглашение друзей.

1. Включи GitHub Pages: репозиторий → **Settings → Pages** → Source: **Deploy from a branch** → ветка с ботом, папка **/docs** → **Save**.
2. Через пару минут приложение откроется по адресу `https://<ник>.github.io/<репозиторий>/`.
3. Впиши этот адрес в `.env`: `MINIAPP_URL=https://...` и перезапусти бота.

Бот сам создаёт ссылки на оплату и ставит каждому пользователю кнопку «Приложение» в меню чата с его данными. Отдельный сервер для приложения не нужен.

## Команды админа
- `/admin`: статистика, выручка и рассылка
- `/give <id> <дней>`: начислить дни пользователю
- `/addpromo <КОД> <дней> <активаций>`: создать промокод
- `/payments [id или @ник]`: список платежей с кнопкой возврата у каждого
- `/refund <charge_id>`: вернуть звёзды по charge_id
- `/testpay`: тестовая оплата на 5 ⭐, чтобы проверить оплату и возврат
- `/server`: состояние сервера без SSH: работает ли VPN и раздача подписок, последняя ошибка, нагрузка, память, диск
- `/backup`: прислать резервную копию базы и настроек VPN
- `/traffic`: трафик за всё время, кто больше всех тратит, сколько устройств онлайн, кто отключён за превышение
- `/funnel`: воронка продаж за всё время и по гостям за последние 30 дней

Рассылка из `/admin` идёт в фоне: бот в это время отвечает гостям. Если Telegram просит подождать, бот ждёт и отправляет то же сообщение ещё раз. В конце приходит отчёт, сколько доставлено.

Если VPN не смог применить настройки (Xray отклонил конфиг или не перезапустился), бот сразу пишет админам «⚠️ Проблема с VPN» с текстом ошибки. Прежний рабочий конфиг при этом остаётся.

## Резервные копии
Раз в сутки бот присылает админам два файла: `bot.db` (гости, подписки, платежи) и `vpn.json` (секрет ключей, страны, мосты). Отключить: `BACKUP_DAILY=0`. Храни их у себя и никому не пересылай.

Кроме Telegram копия сохраняется на диске сервера (`backups/` рядом с базой, последние 7 штук), а если указать `BACKUP_RCLONE`, то ещё и в облако. Так копия не пропадёт, если что-то случится с Telegram-аккаунтом админа.

- **Шифрование.** Впиши в `.env` пароль `BACKUP_PASSWORD=...`. Тогда копия приходит одним архивом `aurora-ДАТА.tar.gz.enc`, зашифрованным AES-256. Пароль храни отдельно от копий: без него копию не открыть. Расшифровать:
  ```bash
  openssl enc -d -aes-256-cbc -pbkdf2 -iter 200000 -in aurora-ДАТА.tar.gz.enc | tar xz
  ```
- **Облако.** На сервере один раз выполни `rclone config` и добавь хранилище (Яндекс Диск, Google Drive, S3 и другие). Затем впиши в `.env`, например, `BACKUP_RCLONE=yadisk:aurora` и перезапусти бота: `systemctl restart aurora-bot`. Без пароля бот предупредит, что копия уходит в облако незашифрованной.

Как восстановить на новом или сброшенном сервере:
1. Запусти установщик и ответь на вопросы как обычно.
2. Останови бота: `systemctl stop aurora-bot`.
3. Положи файлы из копии на место (например, через SFTP в Termius): `bot.db` → `/opt/aurora/vpn-bot/bot.db`, `vpn.json` → `/var/lib/aurora/vpn.json`.
4. Запусти бота: `systemctl start aurora-bot`.

Подписки и сроки вернутся. Ключи Reality на новом сервере другие, поэтому клиентам достаточно обновить подписку в приложении, а если сменился IP сервера, заново скопировать ссылку из бота.

## Установка на сервер
Нужен VPS на Ubuntu 22.04/24.04 или Debian с выделенным IPv4. Зайди на него по SSH (с Android подойдёт Termux: `pkg install openssh`, затем `ssh root@IP`) и выполни:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Saske356/Saske356/claude/android-usage-ql87m8/vpn-bot/install.sh)
```

Установщик сам поставит Xray (VLESS Reality на TCP 443), Hysteria2 (UDP 443), бота, раздачу подписок (порт 2096), включит BBR, большие буферы UDP и автозапуск. Он спросит токен бота, твой Telegram ID и название страны сервера. Настройки останутся только на сервере, в `/opt/aurora/vpn-bot/.env`. Повторный запуск той же команды обновляет бота и сохраняет настройки.

Если в конце что-то не запустилось, установщик покажет две команды: их вывод пригодится, чтобы найти причину.

## Несколько стран на одном сервере
Клиенты всегда подключаются к твоему серверу, а сервер выпускает трафик либо напрямую, либо через прокси другой страны. Сайты видят IP этой страны.

1. Купи недорогие серверные IPv4-прокси (SOCKS5 или HTTP) в нужных странах. Проверь, что продавец разрешает такое использование.
2. Добавь страну командой в боте:
   `/addloc nl 🇳🇱 Нидерланды | socks5://логин:пароль@ip:порт`
3. Список стран: `/locations`, удаление: `/delloc nl`.

Каждый клиент получает **одну ссылку-подписку**. В Hiddify, v2rayNG или Streisand она превращается в список стран и показывает дату окончания доступа. Новые страны появляются у клиентов сами при обновлении подписки.

Перед каждым применением бот проверяет конфиг самим Xray и при ошибке оставляет прежний рабочий.

Ключи выдаются и отключаются **без перезапуска Xray**, через его API на `127.0.0.1:10085`, поэтому покупка или окончание чужой подписки не рвёт подключения остальных. Xray перезапускается только при смене стран, мостов или сайта маскировки. Если API почему-то не ответил, бот применяет конфиг целиком, как раньше.

Каждые 10 минут бот проверяет прокси стран, добавленных вручную: открывает через каждый настоящее HTTPS-подключение. Так ловится не только выключенный прокси, но и истёкший логин. Если прокси не работает, страна скрывается из подписки, а тебе приходит сообщение. Когда прокси оживает, страна возвращается сама.

## Авто-страны из публичных прокси
Бот умеет сам брать бесплатные прокси из открытых списков, добавлять из них страны и менять прокси, когда он перестаёт отвечать. Включается командой `/autoproxy on`, по умолчанию выключено.

> ⚠️ Публичные прокси медленные и живут от минут до часов. Их владельцы видят, к каким адресам идут подключения клиентов (содержимое HTTPS-сайтов остаётся зашифрованным). Это бесплатное дополнение, а не замена купленным прокси: для платящих клиентов надёжнее раздел выше.

Как это устроено:
- **Списки.** Прокси берутся из трёх открытых источников (proxifly, proxyscrape, geonode). Если один недоступен, работают остальные.
- **Проверка.** Через каждый прокси бот открывает настоящее HTTPS-подключение и проверяет сертификат сайта. Прокси, который не умеет пересылать HTTPS или подменяет шифрование, отбрасывается. Страна определяется по тому, откуда прокси на самом деле выходит в интернет, а не по записи в списке. Прокси, которые пускают только на порт 443, тоже отбрасываются: через них не работают обычные сайты и часть приложений.
- **Без спешки.** За одну проверку бот пробует не больше 60 новых прокси, начиная с тех, у кого лучше история в списках. Сотни подключений к чужим адресам подряд хостинг может принять за сканирование сети, поэтому первые страны появляются за несколько минут, а полный набор собирается постепенно.
- **Запасные.** У каждой страны есть рабочий прокси и до двух запасных. Если рабочий не ответил, это же подключение сразу уходит через запасной.
- **Наперегонки.** Если рабочий прокси не ответил за своё обычное время (не дольше 2,5 секунды), параллельно запускается запасной, и подключение идёт через того, кто ответил первым. Зависший прокси больше не стоит клиенту долгих пауз.
- **Самый быстрый — рабочий.** Ретранслятор замеряет скорость каждого прокси на настоящих подключениях. Если запасной стабильно хотя бы на 40% быстрее рабочего, он становится рабочим. Плановая проверка раз в 5 минут делает то же по своим замерам.
- **Без перезапуска VPN.** Xray подключается не к публичному прокси, а к ретранслятору внутри бота (`127.0.0.1:20808`), и тот сам выбирает живой прокси. Поэтому замена прокси не перезапускает Xray и не рвёт подключения остальных клиентов. Xray перезапускается, только когда меняется набор стран, и не чаще одного раза за проверку.
- **Перепроверка.** Раз в 5 минут бот проверяет все прокси авто-стран, убирает умершие и добирает новые. Если живых прокси для страны нет, она прячется из подписки и возвращается, когда прокси найдётся. При подборе страна, которая не вернулась за 6 часов, уступает место другой.
- **Защита от ложной тревоги.** Если проверочный сайт недоступен с самого сервера, бот пропускает проверку и ничего не меняет.
- **Защита основного VPN.** Если Xray не принимает конфиг с авто-странами, бот применяет конфиг без них и пишет тебе причину. Основная страна, купленные прокси и новые клиенты от авто-стран не зависят.

Команды:
- `/autoproxy`: состояние, текущие прокси, их скорость и число замен
- `/autoproxy on`: включить, бот сразу начнёт искать прокси
- `/autoproxy off`: выключить и убрать авто-страны
- `/autoproxy now`: проверить и обновить сейчас, результат придёт сообщением
- `/autoproxy test`: проверить каждую страну так, как подключается клиент, и состояние Xray
- `/autoproxy countries nl de us`: держать именно эти страны (коды из двух букв)
- `/autoproxy countries auto`: бот подбирает страны сам, начиная с популярных
- `/autoproxy max 8`: сколько стран держать при подборе
- `/autoproxy notify off`: не присылать сообщения о заменах

В `/locations` авто-страны помечены значком 🤖. Страны, добавленные через `/addloc`, бот не трогает. Если убрать авто-страну через `/delloc`, бот больше не добавит её сам; вернуть её можно командой `/autoproxy include nl`.

Через авто-страны идёт только TCP: публичные прокси не пересылают UDP. Запросы DNS клиентов этих стран сервер отправляет сам, остальной UDP отклоняется, и приложения переходят на обычное подключение.

Стартовые значения можно задать в `.env` (`AUTO_PROXY`, `AUTO_PROXY_COUNTRIES`, `AUTO_PROXY_MAX`). Они читаются только при первом запуске, дальше настройки меняются командами. Порт ретранслятора задаётся через `AUTO_RELAY_PORT`.

Проверка без сервера: `python3 -m unittest discover -s tests` поднимает на своём компьютере тестовые прокси и проверяет поиск, замену и ретранслятор.

## Сайт маскировки
VPN выдаёт подключение за обращение к обычному сайту (Reality). Имя этого сайта видно оператору в первом пакете, поэтому неудачный выбор приводит к обрывам. Сайтом управляет команда `/sni` в боте:

- `/sni`: какой сайт сейчас и какие настройки
- `/sni next`: подобрать и поставить другой сайт сейчас
- `/sni list`: какие сайты подходят с этого сервера
- `/sni www.example.com`: поставить конкретный сайт
- `/sni every 24`: менять сайт каждые 24 часа, `/sni every off`: не менять по расписанию
- `/sni auto off`: не менять сайт при сбое

Раз в 10 минут бот проверяет, что сайт отвечает с сервера по TLS 1.3 и HTTP/2. Если сайт три раза подряд не ответил, бот сам ставит другой и пишет админам. Смена по расписанию выключена, пока её не включить: сама по себе она от блокировки не спасает, а клиентам после каждой смены нужна обновлённая подписка.

В списке бота нет Microsoft, Apple и других самых известных сайтов: их адреса наперечёт, чужой сервер под таким именем заметен сразу, и Xray сам предупреждает, что это повышает риск блокировки. Поставить такой сайт вручную можно, бот покажет предупреждение.

После смены приложения получают новые ключи при обновлении подписки, сами они делают это раз в час. Если новый сайт отвечает и на чужое имя, ключи с прежним сайтом принимаются ещё сутки.

## Быстрый режим Hysteria2
Установщик ставит рядом с Xray сервер [Hysteria2](https://v2.hysteria.network/). Он работает по UDP на том же порту 443 (Xray занимает 443 по TCP, они не мешают друг другу). У каждого гостя в подписке появляется пункт «Страна ⚡ Hysteria2» сразу после основной страны.

- **Почему быстрее.** Hysteria2 построен на QUIC: при потерях пакетов на мобильной связи он не замедляется так сильно, как TCP, а подключение устанавливается быстрее. Чем хуже связь, тем заметнее разница.
- **Когда не работает.** Некоторые мобильные операторы режут или замедляют UDP. Тогда этот пункт просто не подключается, а Reality в той же подписке работает как прежде. Hiddify с автовыбором переключается сам.
- **Ключи.** Hysteria не хранит список пользователей: при каждом подключении он спрашивает бота (`127.0.0.1:20809`), активна ли подписка. Выдача и отключение доступа ничего не перезапускают. Если бот остановлен, новые подключения Hysteria2 не проходят, а Reality продолжает работать.
- **Сертификат.** Установщик делает свой сертификат, а его отпечаток (`pinSHA256`) вписывается в ссылку. Домен не нужен, подменить сервер нельзя.
- **Если оператор режет QUIC.** Впиши в `.env` любой длинный пароль `HY2_OBFS_PASSWORD=...` и запусти установщик ещё раз. Пакеты станут похожи на случайные данные, а ссылки у клиентов обновятся вместе с подпиской.
- **Выключить.** `HY2=0 bash <(curl ...install.sh)` не ставит Hysteria2. Чтобы убрать его с уже настроенного сервера, впиши `HY2=0` в `.env`, перезапусти бота и выполни `systemctl disable --now hysteria-server`.

Открой у хостинга **UDP 443**, если у него есть свой файрвол в панели: установщик открывает порт только в `ufw` на самом сервере.

### Как получить самый низкий пинг
Пинг почти целиком зависит от расстояния и маршрута между телефоном и сервером, а не от протокола: Reality и Hysteria2 добавляют единицы миллисекунд.
1. Бери сервер поближе к клиентам: из России обычно быстрее всего Финляндия, Эстония, Нидерланды, Германия. Пинг у разных хостингов в одной стране отличается в разы, поэтому проверь двух-трёх.
2. Подключайся напрямую к основной стране. Авто-страны и мосты добавляют лишний узел и всегда дают пинг выше.
3. На мобильной связи выбери «⚡ Hysteria2»: на потерях пакетов разница больше всего.

## Лимит устройств
Раз в 5 минут бот спрашивает у Xray, с каких адресов сейчас подключены ключи каждой подписки, а у Hysteria2 — сколько у неё подключений. Разные адреса почти всегда означают разные устройства.

- Если устройств больше, чем оплачено, две проверки подряд (около 10 минут), гость получает предупреждение с кнопкой «Ещё подписка».
- Если превышение продолжается ещё 15 минут, подписка отключается на 30 минут, затем включается сама. Админам приходит сообщение.
- Несколько устройств за одним роутером или за мостом видны как одно, поэтому проверка скорее мягче, чем строже. Телефон, который переключился с Wi-Fi на мобильную сеть, не считается за два устройства: одной проверки для решения мало.

Настройки: `DEVICE_LIMIT=block` (по умолчанию), `warn` — только предупреждать, `off` — не проверять. Время отключения — `DEVICE_BLOCK_MINUTES`.

## Скидки и возврат гостей
- За 3 часа до конца пробного периода бот напоминает о нём с кнопками тарифов (`TRIAL_REMIND_HOURS`).
- Если гость не купил, после конца пробного он получает скидку 15% на первую покупку на 72 часа (`TRIAL_OFFER`, `OFFER_HOURS`).
- Через 3 и 7 дней после окончания всех подписок гость получает персональную скидку 20% и 30% (`WINBACK=3:20,7:30`, пусто — выключено). Каждое предложение приходит один раз. Тем, кто ушёл больше 30 дней назад, бот не пишет.
- Скидка видна в тарифах и на кнопке главного меню и действует только на разовую оплату: при автопродлении она списывалась бы каждый месяц. После оплаты скидка сгорает. Сколько оплат прошло по скидкам, видно в `/funnel`.

## Обход белых списков (мосты)
Когда мобильный интернет переходит на белые списки, зарубежные серверы недоступны, а российские обычно остаются. Мост — это недорогой российский сервер, который пересылает подключения на основной:

клиент → мост в России → основной сервер → интернет

1. Возьми дешёвый VPS в России с Ubuntu или Debian. Какие сети остаются доступны при белых списках, зависит от региона и оператора, поэтому мост стоит проверить на своём операторе.
2. Зайди на него по SSH и запусти установщик в режиме моста:
   ```bash
   bash <(curl -fsSL https://raw.githubusercontent.com/Saske356/Saske356/claude/android-usage-ql87m8/vpn-bot/install.sh) bridge
   ```
   Он спросит IP основного сервера и в конце покажет команду для бота.
3. В боте: `/addbridge ru1 🇷🇺 Обход | IP_МОСТА`. У всех клиентов в подписке появится пункт «🇷🇺 Обход».

Мост просто пересылает трафик и ничего не хранит: пользователей, ключи и оплату по-прежнему ведёт основной сервер. Мост пересылает только TCP 443, поэтому через него работает Reality, а Hysteria2 — только напрямую. Третьим полем можно указать сайт для маскировки: `| vk.com`. Делай это, только если без него мост не проходит: маскировка под сайт, который не совпадает с настройкой Reality, проще распознаётся.

Своя страна для своего движка: в `vpn.py` можно подключить любой другой класс с методами `issue()` и `revoke()`.

## Диагностика и тесты
Если клиенты не могут подключиться, запусти на сервере диагностику. Она ничего не меняет, не печатает токен и ключи, сама подключается к VPN так же, как клиент, и говорит, где проблема: в настройке сервера или по дороге к нему.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Saske356/Saske356/claude/android-usage-ql87m8/vpn-bot/diag.sh)
```

Если сервер исправен, а телефон не подключается, запусти её с параметром `watch` и за минуту нажми в приложении проверку пинга или подключись. Она покажет, на каком шаге обрывается подключение телефона: не доходит до порта, обрывается по дороге, отклоняется сервером или принимается. На эту минуту включается подробный журнал Xray (он дважды перезапускается), потом настройки возвращаются как были.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Saske356/Saske356/claude/android-usage-ql87m8/vpn-bot/diag.sh) watch
```

Если наблюдение показало, что связь с сервером устанавливается, но данные от телефона не приходят, оператор распознаёт подключение по первому пакету, в котором виден сайт маскировки. Смени его одной командой:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Saske356/Saske356/claude/android-usage-ql87m8/vpn-bot/sni.sh)
```

Она проверяет с сервера список сайтов (TLS 1.3, HTTP/2, настоящий сертификат), пропускает те, о которых предупреждает сам Xray, переключает сервер и делает пробное подключение. Если VPN с новым сайтом не заработал, прежний сайт возвращается сам. После смены клиентам нужно обновить подписку в приложении. С параметром `list` команда только показывает подходящие сайты, а с именем сайта ставит именно его.

Перед любым изменением кода прогоняй общий набор тестов из папки бота:

```bash
pip install -r requirements.txt   # без библиотек бота сквозной тест бота пропускается
python3 -m unittest discover -s tests
```

На GitHub те же тесты запускаются сами при каждом пуше и в каждом пулл-реквесте (`.github/workflows/tests.yml`), на Python 3.11–3.13.

Команды установки, диагностики и смены сайта скачивают код из основной ветки репозитория. Новые правки попадают на сервер после того, как их ветку слили в основную, и установщик запущен ещё раз. Поставить другую ветку можно так: `BRANCH=имя-ветки bash <(curl ...install.sh)`.

В нём сценарии бота от /start до возврата (`test_bot_flows.py`), модуль VPN и установщик (`test_xray_core.py`) и авто-страны (`test_auto_proxy.py`). В сеть и в Telegram тесты не ходят.
