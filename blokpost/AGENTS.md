# Блокпост — устройство кода и правила для параллельной работы

Мобильный тактический шутер на three.js r149 (UMD, глобальный `THREE`). Страница `index.html` (без `<html>/<head>/<body>` —
обёртку добавляет хостинг артефактов) подключает классические скрипты из `src/` по порядку. У всех скриптов общая глобальная
область видимости: `const`/`let`/`function` верхнего уровня одного файла видны в остальных. Код верхнего уровня выполняется
при загрузке по порядку тегов, поэтому файл может *вызывать при загрузке* только то, что объявлено в файлах выше.

## Ограничения хостинга
- Внешние скрипты только с cdnjs / jsdelivr / unpkg с точной версией. Никаких fetch к сторонним сайтам, никаких внешних картинок,
  моделей и звуков — всё генерируется кодом (canvas-текстуры, геометрия, WebAudio).
- `localStorage` только в try/catch. `alert/confirm/prompt` не работают.
- Целевое устройство — средний Android-телефон в браузере, горизонтально. Следим за числом вызовов отрисовки и полигонов.

## Авторские права
Это оригинальная игра жанра. Нельзя: названия и термины чужих игр (Counter-Strike, CS, Standoff, «контр-террористы», «бомба C4»),
копии их карт (dust2, mirage, inferno, sandstone и т.п.) и их раскладки, логотипы, реальные торговые марки оружия
(AK, M4, AWP, Glock, Desert Eagle…). Оружие — с вымышленными названиями, внешне правдоподобное, но не копия конкретной модели.
Используем свои слова: «Атака/Защита», «заряд», «Точка А / Точка Б».

Чужой файл правим только если без этого никак, и минимально (пара строк), с комментарием `// [имя-направления]`.
Свои новые элементы интерфейса создаём из JS внутри `#hud` / `#menu .card`, стили — через `injectCSS('имя', css)`.
Новые файлы можно добавлять: тег `<script>` вставляется в `index.html` в нужное место списка.

## Контракты между модулями
- `input.crouch`, `input.walk`, `input.use` — удержание (ставит UX, читают игрок/режимы).
  `input.useAvailable` + `input.useLabel` — игровой код сообщает, что сейчас доступно действие (например «Заложить»), UX показывает кнопку.
- Разовые действия через шину: `bus.emit('action:knife')`, `'action:grenade'` (переключить/выбрать гранату), `'action:drop'`.
- Боец (`unit`): `pos, vx, vz, yaw, pitch, hp, armor, alive, team ('A'|'B'), cur (ключ оружия), primary, ammo, crouch, isPlayer`.
  Режим «Подрыв» добавляет `unit.side` ('atk'|'def'), `unit.hasCharge`, `unit.planting`, `unit.defusing`.
- `SITES`, `inSite(x,z)`, `spawnZones.atk/def` — из `map.js`. Позиции появления команд по сторонам берутся через `spawnZones[unit.side]`.
- Бой предоставляет `throwGrenade(unit, type, dirVec3)` (type: 'he' | 'flash' | 'smoke') и `smokeBlocks(ax,ay,az,bx,by,bz)` —
  дым закрывает видимость; ИИ ботов учитывает его в `perceive`. Ослепление: `unit.flashT` (сек), боты при `flashT>0` не видят.
- Карта может менять размер и сетку; имена `CELL, MW, MH, grid, TOPS, spawns, cellCh, chAt, walkable, openCells, collide, groundAt,
  los, findPath` и их сигнатуры сохраняются.
- События для звука/интерфейса: `bus.emit('kill', victim, attacker, wKey, head)`, `bus.emit('round:start')`, `bus.emit('round:end', winner)`.

## Проверка
`node tools/smoke.js <tdm|comp|allies|...> <секунд> [папка-для-скриншотов]` — запускает матч в Chromium (эмуляция телефона
844×390), печатает состояние и ошибки консоли, код выхода ≠ 0 при ошибках. Перед коммитом — без ошибок.
