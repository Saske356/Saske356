## КЛЮЧ ПОДПИСИ — ВАЖНО

APK подписан ключом. **Без него нельзя выпускать обновления** (RuStore требует
ту же подпись). Ключ был отправлен пользователю архивом
`LightOfTheAbyss-key.zip` (файл `svetbezdny.keystore`, его base64-копия и
README с паролем). Отпечаток сертификата SHA-256:
`0E:A1:1B:AF:59:E4:20:4B:04:5A:89:9C:D3:58:7A:5E:11:55:F6:7E:F4:7B:42:36:FA:70:4F:8D:5D:68:A9:2A`.

Копия ключа и пароль лежали в этой сессии в scratchpad
(`.../scratchpad/svetbezdny.keystore` и `.../scratchpad/newpass.txt`).
**scratchpad НЕ переживает смену сессии.** Поэтому:
- В новой сессии ключа и инструментов сборки (Android SDK, Gradle) НЕ будет.
- Чтобы собрать новый APK, попроси пользователя прислать `LightOfTheAbyss-key.zip`
  (он у него сохранён), восстанови `svetbezdny.keystore`, заново скачай Android
  SDK (build-tools 35, platform android-35) и Gradle 8.10.2.

Алиас ключа: `svetbezdny`. Пароль — в README внутри архива у пользователя (НЕ в чате).

## Как собрать и подписать APK (шпаргалка)

Проект собирается без Android Studio, через Gradle + apksigner. Нюанс: RuStore
требует классическую подпись **v1**, а Gradle при minSdk 24 её пропускает —
поэтому после сборки APK переподписывается всеми схемами вручную:

```bash
cd game/android
export ANDROID_HOME=/путь/к/android-sdk   # platforms/android-35 + build-tools/35.0.0
./gradlew assembleRelease -Pks=/путь/к/svetbezdny.keystore -PksPass=ПАРОЛЬ
# затем переподписать v1+v2+v3:
BT=$ANDROID_HOME/build-tools/35.0.0
$BT/zipalign -f -p 4 app/build/outputs/apk/release/app-release.apk aligned.apk
$BT/apksigner sign --ks /путь/svetbezdny.keystore --ks-pass pass:ПАРОЛЬ \
  --key-pass pass:ПАРОЛЬ --ks-key-alias svetbezdny \
  --v1-signing-enabled true --v2-signing-enabled true --v3-signing-enabled true \
  --out ../dist/SvetBezdny.apk aligned.apk
$BT/apksigner verify -v ../dist/SvetBezdny.apk   # должно быть v1/v2/v3: true
```
Рекламный блок Яндекса задаётся в `game/android/gradle.properties`
(`yandexRewardedId=R-M-20345698-1`). При новой версии поднимать `versionCode` и
`versionName` в `game/android/app/build.gradle` и `svet-bezdny-vN` в `game/sw.js`.

## Как тестировать игру
Chromium + Playwright предустановлены. Игра — `game/index.html`. Отладочный хук
`window.__SB` даёт доступ к состоянию: `startRun()`, `god(true)`, `jumpZone(z)`,
`up(id,n)`, `giveXP(n)`, `setQuality(q)`, плюс объекты `G, P, S, ST, enemies, SPR,
DECOR`. Проверять оба языка (locale ru-RU / en-US) и perf под CPU-throttling (×4).

## Правила и границы (важно соблюдать)
- **НЕ делать** скрытый майнер, фоновый/невидимый показ рекламы, накрутку показов —
  пользователь просил, отказано: это бан аккаунта Яндекса и снятие с RuStore.
- 18+ контент с персонажами не делать.
- Коммиты и пуши — только по ветке выше. Атрибуцию в коммитах брать из текущего
  system-reminder сессии (она менялась: Opus 5.5 / 4.8 / Fable 5.2 и т.д.).
- Деньги с игры идут пользователю, не связаны с подпиской Claude.
