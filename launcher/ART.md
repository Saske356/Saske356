# Иллюстрации для лаунчера

Готовые картинки кладите в `android/assets/launcher/img/` под этими именами и пересоберите APK (`android/build.sh`).
Если файла нет, лаунчер показывает оформление по умолчанию.

| Файл | Размер | Что это |
|---|---|---|
| `img/bg.jpg` | 1920×1080 (JPG, до 600 КБ) | фон главного экрана **вместо** живой 3D-сцены города (необязательно) |
| `img/loading.jpg` | 1920×1080 (JPG, до 600 КБ) | арт экрана загрузки игровых данных (как сезонные арты у больших проектов) |
| `img/logo.png` | 1024×256 (PNG с прозрачностью) | логотип вместо текстового «ONIKS RP» |
| `icon-512.png` | 512×512 (PNG) | иконка; после замены нарежьте её в `res/mipmap-*` |

Иконку для Android нужно нарезать: замените `android/icon-512.png` и выполните

```bash
python3 -c "from PIL import Image; im=Image.open('android/icon-512.png').convert('RGBA'); \
[im.resize((n,n), Image.LANCZOS).save(f'android/res/mipmap-{d}/ic_launcher.png') for d,n in \
{'mdpi':48,'hdpi':72,'xhdpi':96,'xxhdpi':144,'xxxhdpi':192}.items()]"
```

## Запросы для нейросети (ChatGPT, Midjourney и т. п.)

Важно: просите **оригинальный** стиль. Не пишите «как в Black Russia» или «как в GTA» и не
просите их персонажей, машины и логотипы: такую картинку нельзя законно использовать в проекте.

**Арт экрана загрузки (loading.jpg) — главный «вау»-элемент:**
> Кинематографичный арт 16:9 для экрана загрузки мобильной игры. Ночная улица современного российского
> города после дождя: на переднем плане справа — эффектный спортивный автомобиль оригинального дизайна
> (не существующая марка) с оранжевыми акцентами и включёнными фарами, мокрая брусчатка отражает
> огни, лёгкий туман, неоновые вывески без читаемого текста. Нижняя треть кадра спокойная (там полоса
> загрузки), по центру внизу свободное место под логотип. Без надписей, логотипов и водяных знаков.

Для праздников меняйте только этот файл: зимний, хэллоуинский, летний вариант — и пересоберите APK.

**Фон (bg.jpg):**
> Широкая иллюстрация 16:9 для экрана мобильной игры. Вечерний современный российский город:
> панельные дома и стеклянные высотки, мокрый асфальт с отражениями фонарей, машины со светящимися фарами
> на широком проспекте, тёплый оранжевый закат переходит в тёмно-синее небо. Кинематографичный свет,
> стилизованный полуреализм. Левая треть кадра спокойная и тёмная (там будет текст). Без надписей,
> логотипов, водяных знаков и реальных марок машин.

**Логотип (logo.png):**
> Логотип игры «ONIKS RP» на прозрачном фоне, горизонтальный, 4:1. Слово «ONIKS» — крупный жирный
> геометрический шрифт, глянцевый чёрный камень (оникс) с тонкой оранжевой подсветкой граней (#FF8A3D);
> буквы «RP» — маленькие, оранжевые, справа сверху. Слева от слова — огранённый чёрный камень
> с оранжевыми рёбрами. Без лишнего фона и надписей.

**Иконка (icon-512.png):**
> Иконка мобильного приложения 512×512, квадрат со скруглёнными углами, тёмно-графитовый фон.
> По центру — огранённый драгоценный камень из чёрного оникса с глянцевым бликом, рёбра светятся
> оранжевым (#FF8A3D), мягкое оранжевое свечение за камнем. Плоский современный стиль, читается в маленьком размере.
