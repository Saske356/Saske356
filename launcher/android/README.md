# Лаунчер Новоград RP для Android

Экраны: заставка → проверка файлов → «Доступно обновление! Размер … МБ» → полноэкранная загрузка
с полосой и скоростью → главный экран (имя, фамилия, пароль, сервер с кнопкой смены, соцсети,
поддержка, новости, настройки, «ИГРАТЬ»). На фоне — живая 3D-сцена ночного города из модулей игры
(копируются из `game/` при сборке), вместо неё можно положить арт. Шрифт Montserrat (OFL) вшит в APK.
Соцсети, поддержка и встроенные серверы задаются в `assets/launcher/config.js`.

Приложение со списком серверов (онлайн, пинг), новостями сервера, вводом ника и пароля,
настройкой графики и кнопкой «Играть». Игра открывается на весь экран в альбомной ориентации,
вход выполняется автоматически. Кнопка «Назад» в игре спрашивает, выйти ли в лаунчер.

## Игровой кэш (как у больших мобильных RP)

При нажатии «Играть» лаунчер запрашивает у сервера `GET /api/manifest` — список файлов игры с sha256 и размерами —
и сверяет его с файлами на телефоне. Недостающие и изменённые файлы скачиваются с прогресс-баром и скоростью,
после обрыва связи загрузка продолжается с того же места (HTTP Range), каждый файл проверяется по хешу.
Затем игра запускается **с телефона** (`http://game.local/…` подставляется из кэша), а сервер нужен только для мультиплеера.

Что попадает в кэш: `game/public/`, `game/shared/`, `game/cache/` (модели, текстуры, звуки) и `three.module.js`.
Чтобы выпустить обновление, достаточно положить новые файлы на сервер — лаунчер докачает только разницу.
В настройках лаунчера есть кнопка «Перекачать файлы игры».

## Как это устроено

- `assets/launcher/` — интерфейс лаунчера (HTML/CSS/JS). Его можно открыть и в обычном браузере для проверки.
- `assets/launcher/config.js` — встроенный список серверов. **Впишите сюда адрес своего сервера перед сборкой.**
- `src/ru/novograd/rp/` — Java: `MainActivity` (лаунчер и мост в JS), `GameActivity` (игра из кэша),
  `CacheSync` (загрузка и проверка кэша, без зависимостей от Android), `Screen` (полноэкранный режим, WebView).
- Сервер игры отдаёт `GET /api/status` → `{ name, online, max, version, news }`.
  Новости правятся в `game/news.json`, имя и лимит — переменными `SERVER_NAME` и `MAX_PLAYERS`.

## Сборка

Нужны JDK 17+ и Android SDK с `platforms;android-34` и `build-tools;36.0.0` (или новее). Gradle не нужен.
Версию лаунчера поднимайте в `AndroidManifest.xml` (`versionCode` +1 и `versionName`).

```bash
cd launcher/android
ANDROID_HOME=/путь/к/android-sdk ./build.sh
# → build/NovogradRP-<версия>.apk
```

`DEBUG=1 ./build.sh` включает отладку WebView через `chrome://inspect`.

## Ключ подписи

При первой сборке создаётся `keystore/release.jks` и `keystore/password.txt` (в git не попадают).
**Храните их в надёжном месте**: обновление APK устанавливается поверх старого только с тем же ключом.
Чтобы собрать новую версию, положите файлы обратно в `keystore/` и увеличьте `versionCode`/`versionName`
в `AndroidManifest.xml`.

## Иконка

`python3 tools/make_icon.py` перерисовывает `res/mipmap-*/ic_launcher.png` (нужен Pillow).
Можно просто заменить PNG своими.
