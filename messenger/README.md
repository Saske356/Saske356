# Saske Messenger

Зашифрованный веб-мессенджер (в духе Telegram / WhatsApp), работающий как
артефакт на claude.ai.

**Приложение:** https://claude.ai/artifact/LdNrnzQBwAvck1FbFGG7QQ

## Возможности

- Личные и групповые чаты, поиск людей по имени
- Сообщения шифруются на устройстве — в базе хранится только шифртекст
- Онлайн-статус собеседника и индикатор «печатает…»
- Удаление своих сообщений, отметки непрочитанного
- Светлая и тёмная тема, адаптивная вёрстка (телефон / компьютер)
- Админ-панель владельца: расшифровка и выгрузка любой переписки в файл

## Модель шифрования (escrow — доступ владельца)

Это **не** сквозное шифрование уровня Signal, а осознанный компромисс:
содержимое защищено от посторонних, но владелец может выдать переписку по
законному запросу.

- **Каждое сообщение** шифруется симметрично (AES-256-GCM) ключом чата.
  В базу попадает только шифртекст.
- **Ключ чата** заворачивается (RSA-OAEP 2048) на публичные ключи участников
  и обязательно на **escrow-ключ владельца**. Читать могут участники,
  расшифровать всё может владелец.
- **Личные ключи участников** лежат в их приватном разделе базы
  (`data/users/<id>/identity`), недоступном другим, и синхронизируются между
  устройствами одного аккаунта.
- **Escrow-ключ владельца** создаётся автоматически при первом открытии
  приложения владельцем и хранится в его приватном разделе
  (`data/users/<ownerId>/escrow`). Публичная часть — в `escrow/pub`.

### Что защищено, а что нет

| | |
|---|---|
| Содержимое сообщений | Зашифровано. Не читается в сырой базе и зрителями read-only ссылки. |
| Метаданные (кто с кем, когда) | Видны подписанным участникам организации. |
| Доступ владельца | Владелец расшифровывает любой чат через escrow-ключ. |
| Предел стойкости | Ключи хранятся в базе платформы claude.ai. Для уровня «свой сервер» нужен отдельный бэкенд. |

### Выдача переписки по запросу

1. Откройте приложение как владелец → кнопка **🛡️** (админ-панель).
2. Выберите чат → **Экспорт** — получите расшифрованную переписку в `.txt`
   (имена, время, тексты).
3. **Обязательно сохраните резервную копию escrow-ключа** (кнопка в
   админ-панели). Без него расшифровать переписку невозможно. Файл даёт
   полный доступ к содержимому — храните его как пароль.

## Как подключить людей

- Поделитесь приложением (меню **Share**) и пригласите человека
  **по email как редактора** — тогда он сможет писать.
- По обычной публичной ссылке зритель получает только чтение и не имеет
  ключей, поэтому содержимое чатов ему недоступно.
- Когда новый участник впервые открывает приложение, его публичный ключ
  публикуется автоматически; ключ от чата ему выдаёт любой участник,
  у которого доступ уже есть, при следующем открытии чата.

## Технически

Один файл `index.html`. Возможности среды артефактов claude.ai:

- `db` — общая база: `chats/{id}`, `chats/{id}/blocks/{bNNNNNN}` (блоки
  по ~64 сообщения), `pubkeys/{uid}`, `escrow/pub`, приватные
  `data/users/{id}/identity` и `data/users/{id}/escrow`;
- `user` — профили и поиск людей; `room` — онлайн-статус и «печатает…»;
- `downloads` — выгрузка расшифрованной переписки и резервной копии ключа.

Шифрование — Web Crypto API (RSA-OAEP + AES-GCM). Код работает в браузере
зрителя, поэтому перед реальным использованием протестируйте переписку между
двумя аккаунтами.
