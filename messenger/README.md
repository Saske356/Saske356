# Saske Messenger

Анонимный зашифрованный веб-мессенджер, работающий как артефакт на claude.ai.

**Приложение:** https://claude.ai/artifact/LdNrnzQBwAvck1FbFGG7QQ

## Возможности

- **Добавление только по `@нику`** — поиска по реальным именам нет
- **Реальные имена, фото и email не используются** приложением вообще
  (capability `user` без scope `profile`); аватарки генерируются из псевдонима
- Личные и групповые чаты, сообщения и геопозиция шифруются на устройстве
- **Исчезающие сообщения**: по чату — выкл / 1 час / 24 ч / 7 дней;
  по сроку шифртекст стирается из базы
- Онлайн-статус, «печатает…», удаление своих сообщений
- Светлая / тёмная / системная тема, адаптив (телефон / компьютер)
- Админ-панель владельца: расшифровка и выгрузка переписки (escrow)

## Анонимность — что это даёт и чего не даёт (честно)

Это **анонимность между пользователями**, не от владельца и не от платформы.

| От кого скрыто | Статус |
|---|---|
| Другие пользователи | Видят только `@ник` и цвет-аватар. Настоящее имя/почта/фото недоступны в приложении. |
| Посторонние / read-only ссылка / сырая база | Содержимое и координаты зашифрованы. |
| Владелец сервиса | **Может читать всё** через escrow-ключ (ваше требование для выдачи по запросу). |
| Платформа Anthropic | Технически видит аккаунты и метаданные — артефакт работает на её инфраструктуре. |
| Метаданные (кто с кем, когда) | Видны подписанным участникам. |

Если нужно скрыть переписку **даже от владельца и платформы** (настоящий E2EE
без escrow) — артефакт не подходит, нужен свой сервер/приложение (см. раздел про APK).

## @ники: как устроено и защищено

- Каждый задаёт уникальный `@ник` (3–20 символов: a–z, 0–9, `_`).
- Ник хранится в `handles/<uid>`, писать его может **только сам пользователь**
  (правило `{self}`) — чужой `@ник` подменить нельзя.
- Добавление: `@ник` → запрос `handles` по полю `hl` → `uid` → чат.
- Уникальность проверяется при сохранении (возможна редкая гонка при
  одновременном захвате одинакового ника).

## Шифрование (escrow — доступ владельца)

- Сообщения и координаты: AES-256-GCM ключом чата; в базе только шифртекст.
- Ключ чата заворачивается RSA-OAEP 2048 на публичные ключи участников и на
  escrow-ключ владельца.
- `escrow/pub` пишет только владелец (`write:"owner"`) — редактор не подменит
  escrow-ключ. Проверено.
- `pubkeys/<uid>` пишет только сам пользователь (`{self}`) — защита от MITM.
- UI строится через `textContent` (защита от XSS); ссылки на карту — только из
  проверенных числовых координат.

## Исчезающие сообщения

Срок задаётся на чат (`ttl`). При открытии чата участники тихо «затирают»
просроченные сообщения: шифртекст заменяется на метку удаления, содержимое
исчезает из базы. Работает кооперативно — пока кто-то из участников открывает чат.

## Про отдельное Android-приложение (APK)

Приложение — веб-страница в среде claude.ai; весь бэкенд даёт платформа через
`window.claude`. Вне claude.ai этого API нет, поэтому страницу нельзя просто
завернуть в APK. Настоящий APK — отдельный проект: свой сервер + БД + push,
клиент на React Native / Flutter или веб + Capacitor/TWA, затем сборка и
подпись APK. Крипто-слой (RSA-OAEP + AES-GCM + escrow) переносится почти без
изменений.

## Как подключить людей

- **Share** → пригласить **по email как редактора** (иначе только чтение).
- Каждый задаёт `@ник` в настройках; этим `@ником` его добавляют в чаты.
- Публичная ссылка даёт только чтение и не даёт ключей.

## Технически

Один файл `index.html`. Среда claude.ai: `db` (`chats`, блоки, `pubkeys`,
`handles`, `escrow`, приватные `data/users/{id}/…`), `user` (только id, без
имён), `room` (онлайн, «печатает…»), `downloads` (выгрузка). Крипто — Web
Crypto API. Код выполняется в браузере зрителя — протестируйте переписку между
двумя аккаунтами перед реальным использованием.
