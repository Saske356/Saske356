# Telegraph — мессенджер в стиле Telegram

Веб-мессенджер в реальном времени: Node.js-сервер (HTTP + WebSocket) и клиент на чистом JS без фреймворков.

## Возможности

- Регистрация и вход по имени пользователя и паролю (пароли хешируются scrypt)
- Личные чаты, группы и «Избранное» (чат с самим собой)
- Глобальный поиск людей по имени или `@username`
- Сообщения доставляются мгновенно через WebSocket, работает на нескольких устройствах сразу
- Статусы «в сети» / «был(а) N мин. назад» и индикатор «печатает…»
- Отметки о прочтении: ✓ — отправлено, ✓✓ — прочитано; счётчики непрочитанных
- Ответ на сообщение (двойной клик или контекстное меню), редактирование (в том числе стрелкой ↑), удаление, копирование, пересылка
- Фото, видео, аудио и любые файлы до 20 МБ: кнопка 📎, вставка из буфера обмена или перетаскивание в чат
- Группы: создание, добавление участников, переименование, выход; служебные сообщения о событиях
- Профиль: имя и «о себе»
- Светлая и ночная темы, адаптивная вёрстка для телефона, браузерные уведомления, черновики для каждого чата
- Ссылки и упоминания `@username` кликабельны

## Запуск

```bash
cd messenger
npm install
npm start
```

Откройте http://localhost:3000, зарегистрируйте два аккаунта (например, в обычном и приватном окне) и напишите друг другу.

Переменные окружения:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | Порт сервера |
| `DATA_DIR` | `./data` | Где хранить базу (`db.json`) и загруженные файлы |

Для доступа из интернета поставьте сервер за nginx/Caddy с HTTPS — клиент сам переключится на `wss://`.

## Устройство

- `server.js` — HTTP API (`/api/register`, `/api/login`, `/api/logout`, `/api/upload`), раздача статики и WebSocket `/ws`, через который идут все остальные команды и события
- `public/` — клиент: `index.html`, `style.css`, `app.js`
- Данные хранятся в одном JSON-файле, запись атомарная (через временный файл). Подходит для личного использования и небольших компаний; для большой нагрузки стоит перейти на настоящую БД.
