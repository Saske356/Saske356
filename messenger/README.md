# Орбита

Веб-мессенджер со своим лицом: шифрование на устройствах, звонки, голосовые, реакции, опросы — и прозрачный служебный доступ для ответа на законные запросы.

## Что умеет

**Общение**
- Личные беседы, группы и «Заметки» для себя
- Ответы (двойной клик/свайп влево на телефоне), редактирование (↑), пересылка, закрепы, удаление у всех
- Реакции — панель при наведении, двойной клик ставит 👍
- Опросы с одним или несколькими ответами
- Голосовые сообщения с волной, перемоткой по волне, скоростью 1×/1,5×/2× и автовоспроизведением следующего
- Фото (с размытым превью, пока грузится оригинал), видео и любые файлы до 50 МБ — кнопкой, вставкой или перетаскиванием
- Исчезающие сообщения: 30 с / 5 мин / 1 ч / 1 день / 1 неделя
- Статусы «на связи», «печатает…», «записывает голосовое…», отметки о прочтении, разделитель «Новые сообщения»

**Звонки**
- Аудио- и видеозвонки один на один (WebRTC, напрямую между устройствами)
- Выключение микрофона и камеры, демонстрация экрана, сворачивание звонка в плашку
- Журнал звонков с пропущенными и перезвоном

**Интерфейс**
- Четыре раздела: Беседы, Звонки, Люди, Профиль; панель деталей беседы справа
- Светлая, тёмная и системная тема, семь акцентных цветов, фото профиля
- Адаптивная вёрстка: на телефоне — нижняя навигация и полноэкранные беседы
- Уведомления браузера и синтезированные звуки (без файлов)

## Запуск

Нужен Node.js 22.13 или новее (используется встроенный SQLite).

```bash
cd messenger
npm install
npm start          # http://localhost:3000
```

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | Порт |
| `DATA_DIR` | `./data` | База `orbita.db`, зашифрованные файлы, аватары |
| `ICE_SERVERS` | публичные STUN Google | JSON со списком STUN/TURN для звонков |

Камера и микрофон работают только на `localhost` или по HTTPS. Для работы через интернет поставьте сервер за nginx/Caddy с HTTPS. Чтобы звонки проходили через строгие NAT и мобильные сети, добавьте TURN-сервер (например, coturn):

```bash
ICE_SERVERS='[{"urls":"stun:stun.l.google.com:19302"},{"urls":"turn:turn.example.com:3478","username":"u","credential":"p"}]' npm start
```

## Шифрование и служебный доступ

### Как шифруется переписка
- Пароль не уходит на сервер. Браузер получает из него (PBKDF2, 250 000 итераций) два независимых значения: токен для входа и ключ, которым запечатан личный ключ пользователя (ECDH P-256). Поэтому вход с нового устройства работает, а восстановить забытый пароль нельзя.
- У каждой беседы есть свой случайный ключ AES-256. Для каждого участника он упакован общим ключом ECDH + HKDF. При любом изменении состава группы создаётся новая версия ключа.
- Сообщения шифруются AES-256-GCM. Каждый файл и голосовое шифруются отдельным случайным ключом, сервер хранит только шифротекст.
- Коды безопасности (эмодзи и 60 цифр) позволяют собеседникам убедиться, что сервер не подменил ключи.

### Служебный доступ для правоохранительных органов
Администрация может раскрыть содержимое беседы по законному запросу. Устроено это так:

1. **Настройка.** При первом запуске сервер печатает в консоль одноразовую ссылку `/admin#setup=…`. Администратор открывает её и задаёт фразу доступа (от 12 символов). В браузере создаётся служебная пара ключей, а закрытый ключ запечатывается этой фразой. Сервер хранит его только в запечатанном виде, поэтому без фразы содержимое не прочитает даже тот, у кого есть база данных.
2. **Депонирование.** Клиенты упаковывают ключ каждой беседы ещё и для служебного ключа. Сервер не примет ключи беседы без этой упаковки. Беседы, созданные до настройки, получают новую версию ключа при следующем открытии участником. Более ранние сообщения остаются недоступны администрации, и панель так и показывает.
3. **Доступ.** В `/admin` администратор ищет пользователя, видит его беседы и открывает нужную. Без указания основания (номер и дата запроса) беседа не откроется. Переписка расшифровывается в браузере администратора: текст, фото, голосовые, файлы, опросы с голосами, журнал звонков.
4. **Выгрузка.** Можно выгрузить HTML-протокол (для печати) или JSON с SHA-256 записи для контроля целостности. В выгрузке есть участники, время, основание и дата выгрузки.
5. **Журнал.** Входы, неудачные попытки входа, открытия и выгрузки бесед записываются со временем, основанием и IP-адресом.

**Пользователи об этом знают.** Предупреждение показывается при регистрации, и без согласия аккаунт не создаётся. Оно же есть в начале каждой беседы и в разделе «Шифрование» панели деталей. Скрытого доступа здесь нет. Обещать «сквозное шифрование» и при этом читать переписку означало бы обманывать пользователей.

### Что администрация не получает
- **Содержимое звонков.** Медиа идёт напрямую между устройствами и не записывается. Видно только журнал: кто, кому, когда и сколько длился звонок.
- **Удалённые и исчезнувшие сообщения.** Они удаляются с сервера вместе с файлами.

### Что нужно понимать
- Служебная фраза — ключ ко всей переписке сервиса. Храните её в сейфе, давайте только уполномоченным людям и не держите на самом сервере. Если её потерять, доступ пропадёт навсегда.
- Сервер видит метаданные: кто с кем общается, когда, названия групп, реакции и голоса в опросах.
- Изменённый клиент может упаковать для служебного ключа мусор вместо настоящего ключа беседы. Сервер это проверить не может.
- Конкретные требования закона (сроки хранения, порядок передачи данных, уведомление регулятора и т. п.) зависят от страны и статуса сервиса. Проверьте их с юристом до запуска. Возможно, понадобится, например, отключить исчезающие сообщения или удаление.

## Устройство

```
server/
  index.js    HTTP API, раздача статики, WebSocket, обработчики команд
  db.js       схема SQLite (node:sqlite)
  calls.js    сигнализация звонков WebRTC
  admin.js    служебный доступ: настройка, вход, выдача бесед, журнал аудита
public/
  index.html, css/app.css
  js/crypto.js        вся криптография (WebCrypto)
  js/state.js         состояние, ключи бесед, шифрование сообщений
  js/net.js           WebSocket-RPC, загрузка файлов
  js/main.js          запуск, вход, обработка событий
  js/sidebar.js       разделы: беседы, звонки, люди, профиль
  js/conversation.js  лента, композер, опросы, реакции, панель деталей
  js/media.js         файлы, голосовые, звуки
  js/calls.js         звонки
  js/modals.js        диалоги и меню
  admin.html, js/admin.js   консоль служебного доступа
```
