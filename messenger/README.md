# Saske Messenger

Веб-мессенджер в стиле Telegram / WhatsApp, работающий как артефакт на claude.ai.

**Приложение:** https://claude.ai/artifact/LdNrnzQBwAvck1FbFGG7QQ

## Возможности

- Личные чаты (поиск людей по имени) и групповые чаты
- Общий публичный чат для всех участников
- Сообщения в реальном времени, история хранится в общей базе артефакта
- Онлайн-статус собеседника и индикатор «печатает…»
- Удаление своих сообщений
- Непрочитанные чаты отмечаются точкой
- Светлая и тёмная тема, адаптивная вёрстка (телефон / компьютер)

## Как пригласить друзей

1. Откройте приложение по ссылке выше.
2. Нажмите «Share» (Поделиться) и пригласите человека **по email как редактора** —
   тогда он сможет писать сообщения.
3. Люди, открывшие страницу по обычной публичной ссылке, смогут только читать:
   платформа артефактов не даёт права записи внешним зрителям.

## Устройство

Один файл `index.html`. Используются возможности среды артефактов claude.ai:

- `db` — общая база документов: `chats/{id}` (метаданные чата) и
  `chats/{id}/blocks/{bNNNNNN}` (блоки по ~64 сообщения, чтобы экономить лимит документов);
- `user` — профили: имена, аватары, поиск людей для создания чатов;
- `room` — присутствие: кто сейчас онлайн и кто печатает.

Сообщение — это поле в карте `msgs` внутри блока; параллельные отправки не
затирают друг друга, потому что `update` сливает поля на сервере.
