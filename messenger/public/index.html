Приложение для Android APK

Впервые здесь?

Пароль не покидает устройство. Из него получается ключ, который шифрует ваши переписки и файлы. Сервер видит только шифротекст, поэтому пароль нельзя восстановить.

Переписки и файлы хранятся зашифрованными, но у администрации сервиса есть служебный ключ доступа: по законному запросу содержимое беседы может быть раскрыто и передано правоохранительным органам. Каждый такой доступ фиксируется в журнале. Звонки не записываются. Пароль восстановить нельзя.
