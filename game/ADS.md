# Реклама в «Свет Бездны»

В Android-приложении есть **вознаграждаемая реклама Яндекса** (Yandex Mobile Ads). Игрок смотрит её сам, когда хочет бонус:

| Где | Что даёт |
|---|---|
| После гибели | «Продолжить за рекламу» — воскрешение с 60% здоровья (раз за забег, 5 секунд на решение) |
| Экран итогов | «×2 жемчуга за рекламу» (раз за забег) |
| Выбор улучшения | «Перебор за рекламу», когда обычные переборы кончились (до 2 раз за забег) |

В браузерной версии кнопок рекламы нет. Если реклама не загрузилась (нет интернета), кнопки тоже не показываются, и игра идёт как обычно.

## Сейчас стоит боевой блок
`R-M-20345698-1` — реальный блок «Вознаграждаемая реклама» из Яндекс Партнёров. Чтобы он начал приносить деньги, игра должна быть опубликована в RuStore и пройти проверку модерации Яндекса (обычно до суток после первых показов).

## Как начать зарабатывать
1. Зарегистрируйтесь в **Яндекс Партнёрах** (partner.yandex.ru). Для выплат нужен статус самозанятого или ИП (значит, от 18 лет). Проверьте актуальные условия на сайте.
2. Добавьте мобильное приложение (Android, пакет `com.svetbezdny.game`). Создайте рекламный блок типа **«Вознаграждаемая реклама»** (Rewarded).
3. Скопируйте ID блока (вида `R-M-1234567-1`) в `android/gradle.properties`:
   ```
   yandexRewardedId=R-M-1234567-1
   ```
4. Пересоберите APK (см. ниже) и опубликуйте в **RuStore**. Яндекс может требовать, чтобы приложение было опубликовано в магазине, прежде чем блок начнёт показывать реальную рекламу.

## Сборка APK
Нужны JDK 17+ и Android SDK (platform 35, build-tools 35.0.0).
```bash
cd game/android
export ANDROID_HOME=/путь/к/android-sdk
./gradlew assembleRelease -Pks=/путь/к/svetbezdny.keystore -PksPass=пароль
# готовый файл: app/build/outputs/apk/release/app-release.apk
# RuStore требует классическую подпись v1, а сборщик её пропускает (minSdk 24).
# Поэтому после сборки переподпишите файл всеми схемами:
zipalign -f -p 4 app/build/outputs/apk/release/app-release.apk aligned.apk
apksigner sign --ks /путь/к/svetbezdny.keystore --ks-key-alias svetbezdny \
  --v1-signing-enabled true --v2-signing-enabled true --v3-signing-enabled true \
  --out ../dist/SvetBezdny.apk aligned.apk
```
Ключ подписи храните в надёжном месте и **не загружайте в GitHub**: без того же ключа обновление не встанет поверх старой версии.

## Чего ждать
За 1000 просмотров вознаграждаемой рекламы в России обычно платят от десятков до нескольких сотен рублей — зависит от аудитории. Заметный доход появляется при тысячах активных игроков, поэтому главное — продвижение (ролики в TikTok/Shorts, публикация в RuStore).
