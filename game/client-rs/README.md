# Клиент ONIKS RP на Rust (Bevy)

Свой клиент с нуля: тот же протокол, что у сервера на Rust и у JS-клиента.

```bash
cd game
cargo build --release -p oniks-client
./target/release/oniks-client                     # «Сервер 1» офлайн: сервер запускается внутри клиента
./target/release/oniks-client --map district1     # офлайн на карте из cache/brmap/district1.glb
./target/release/oniks-client --server 1.2.3.4:3000 --name Ivan_Petrov --pass 1234
```

Управление: WASD — ходьба и руль, Shift — бег, Пробел — ручник (в полёте — вверх, C — вниз),
мышь с зажатой кнопкой — камера, колесо — зум, F — сесть/выйти, T — чат, `/ahelp` — админ-команды.
В офлайне вы — главный админ (5 уровень): `/spcar supra`, `/fly`, `/givecash 100000`, `/settime 23` и т. д.

Что уже есть: город из генератора или карта из кэша (со столкновениями по её треугольникам), персонаж с анимацией,
машины из `cache/cars/*.glb` с перекраской и вращением колёс, вождение, полёт, день/ночь, тени, чат, HUD,
другие игроки и машины по сети, встроенный офлайн-сервер с админкой.

Для автопроверок: `--cmd "/spcar supra" --enter --forward 3 --screenshot shot.png --at 10`.
