Политика конфиденциальности игры «Свет Бездны»

Действует с 5 ноября 2026 года.

Что собирает игра

Сама игра не собирает и не отправляет никаких личных данных. Прогресс (рекорды, жемчуг, настройки, достижения) хранится только на вашем устройстве и удаляется вместе с приложением.

Реклама

В Android-версии есть реклама за награду, которую игрок включает сам. Её показывает рекламная сеть Яндекса (Yandex Mobile Ads SDK). Для показа и подсчёта рекламы SDK может обрабатывать технические данные устройства: рекламный идентификатор, модель устройства, версию системы, язык, приблизительное местоположение по IP-адресу и сведения о взаимодействии с рекламой. Эти данные обрабатывает ООО «ЯНДЕКС» по своим правилам: политика конфиденциальности Яндекса.

Сбросить или ограничить рекламный идентификатор можно в настройках Android: «Конфиденциальность» → «Реклама».

Разрешения приложения

  • Интернет — только для загрузки рекламы. Сама игра работает без сети.
  • Вибрация — отклик при попаданиях, отключается в настройках игры.

Дети

Игра не предназначена для сбора данных детей и не запрашивает у игроков никаких сведений о себе.
