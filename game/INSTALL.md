# Как поставить «Свет Бездны» на телефон

Игра — обычная веб-страница, но её можно установить как приложение: своя иконка на главном экране,
запуск на весь экран и работа **без интернета** после первого открытия.

## Вариант А — установить как приложение (рекомендуется)

Один раз включить GitHub Pages (делается с компьютера или из браузера на телефоне):

1. Открой репозиторий на GitHub → **Settings** → слева **Pages**.
2. В блоке **Build and deployment**: Source — **Deploy from a branch**.
3. Branch — **`claude/termux-setup-0ulp7o`**, папка — **`/ (root)`** → **Save**.
4. Подожди 1–2 минуты, пока GitHub опубликует сайт (наверху страницы Pages появится ссылка).

Дальше на телефоне:

1. Открой в **Chrome**: **https://saske356.github.io/Saske356/game/**
2. Нажми меню **⋮** (справа сверху) → **«Установить приложение»**
   (или **«Добавить на главный экран»** → **«Установить»**).
3. На главном экране появится иконка **«Свет Бездны»** — игра запускается на весь экран и работает офлайн.

> Обновления приходят сами: открой игру с интернетом, и при следующем запуске будет новая версия.

## Вариант Б — просто играть в браузере

Открой ту же ссылку **https://saske356.github.io/Saske356/game/** в любом браузере — и играй.
Можно и вовсе без хостинга: скачай `game/index.html` на телефон и открой его в Chrome — вся игра в одном файле
(установки и офлайн-кэша в этом случае не будет, но играть можно).

## Если что-то не так

- **Нет пункта «Установить приложение»** — проверь, что адрес начинается с `https://`, и обнови страницу;
  на некоторых телефонах пункт называется «Добавить на главный экран».
- **Нет звука** — коснись экрана (браузеры включают звук только после касания) и проверь кнопку
  с динамиком в игре.
- **Тормозит** — в «Настройках» оставь «Графика: АВТО» (игра сама подберёт качество) или включи «ЭКОНОМ».
- Прогресс хранится в браузере. Если очистить данные Chrome или сайта, жемчуг и награды сбросятся.

## Вариант C: APK (настоящее приложение)
1. Скачайте `game/dist/SvetBezdny.apk` на телефон (на GitHub: открыть файл → Download).
2. Откройте его. Android спросит разрешение «Установка из неизвестных источников» — разрешите для браузера или файлового менеджера.
3. Нажмите «Установить». Иконка «Свет Бездны» появится на рабочем столе.
4. Если у вас стоит версия 1.0 — новая встанет поверх, прогресс сохранится.

Если Play Защита предупредит «неизвестный разработчик» — это нормально для приложений не из Google Play: нажмите «Всё равно установить».

Приложению нужен интернет только для рекламы — сама игра работает и без него.

Пересобрать APK самому и подключить свою рекламу: см. `game/ADS.md`.
