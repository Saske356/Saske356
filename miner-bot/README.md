# ⛏ Учебный бот-майнер

Telegram-бот, который майнит блоки по принципу Bitcoin (Proof-of-Work на SHA-256)
в своей мини-сети. Майнит **открыто, на вашем сервере**, только по кнопке.
Монеты учебные.

## Запуск

```bash
cd miner-bot
pip install -r requirements.txt
cp .env.example .env      # впишите BOT_TOKEN от @BotFather
python bot.py
```

## Команды

- `/start`: меню
- `/mine`: намайнить блок (видно перебор nonce и скорость в реальном времени)
- `/stop`: остановить майнинг
- `/balance`, `/top`: баланс и топ майнеров
- `/chain`: последние блоки (видно, как блоки сцеплены хешами)
- `/how`: объяснение, как работает майнинг

## Суть

Майнер перебирает `nonce` и считает `SHA256(SHA256(данные блока + nonce))`,
пока хеш не окажется меньше цели (то есть не начнётся с N нулевых бит).
Каждый лишний бит удваивает работу. Сложность подстраивается так, чтобы блок
находился примерно за 10 секунд. Вся логика лежит в `chain.py`.
