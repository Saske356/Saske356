# Машины для CRMP

Шесть оригинальных машин для GTA SA / CRMP с детализированным кузовом и салоном и шестью скинами каждая.
Модели генерирует код (`tools/`): кузов, фары и фонари, салон, колёса и экспорт в форматы RenderWare.

| Файл | Машина | Класс |
|---|---|---|
| `compact_sedan` | «Волжанка С» | компакт-седан |
| `classic_sedan` | «Семёрка» | классика |
| `exec_sedan` | «Сенатор 7» | бизнес-седан |
| `suv` | «Тайга 4×4» | внедорожник |
| `supercar` | «Торо V12» | суперкар |
| `hypercar` | «Аврора W16» | гиперкар |

В папке `build/<машина>/` лежат:

- `<машина>.dff` — модель: кузов, салон, колёса, коллизия COL3 внутри файла;
- `<машина>.txd` — текстуры с обычной окраской (меняется в игре через `/color`);
- `<машина>_police.txd`, `_taxi.txd`, `_vinyl_stripes.txd`, `_vinyl_tribal.txd`, `_vinyl_camo.txd` — остальные скины;
- `textures/*.png` — все текстуры в PNG, для мобильного TXD Tool и для ручной правки;
- `<машина>.glb` — та же модель для просмотрщика и Blender;
- `render_*.png` — рендеры.

## Что есть в модели

- Отдельные узлы GTA: `chassis`, `chassis_vlo` (LOD), двери `door_lf/rf/lr/rr`, `bonnet`, `boot`, `bump_front`, `bump_rear`, `windscreen`. У каждого есть версии `_ok` и `_dam`, поэтому машина бьётся и детали отлетают.
- Колёса `wheel` с диском, шиной с протектором и тормозным диском. Узлы `wheel_*_dummy`, `ped_frontseat`, `ped_backseat`, `headlights`, `taillights`, `exhaust`, `engine`, `petrolcap`.
- Фары и фонари используют стандартные цвета материалов SA, поэтому в игре они загораются, а стоп‑сигналы работают сами: фара левая 255,175,0, фара правая 0,255,200, фонарь левый 185,255,0, фонарь правый 255,60,0. Текстура ламп — стандартная `vehiclelights128` из `vehicle.txd`.
- Поворотники — отдельные материалы в цветах ImVehFt / VehFuncs: перед‑лев 255,173,0, перед‑прав 0,255,198, зад‑лев 184,255,0, зад‑прав 255,59,0. Ещё есть повторители на зеркалах.
- Руль — узел `f_steer`, стрелки — `f_spdo` (спидометр) и `f_tach` (тахометр). Это имена узлов VehFuncs. Стрелки в покое стоят на нуле и поворачиваются вокруг своей оси Y.
- Салон: сиденья с боковой поддержкой и прострочкой, торпедо, приборная панель со шкалами, экран, климат, дефлекторы, консоль, рычаг КПП, педали, обшивки дверей, потолок, зеркало.
- Краска — основной цвет GTA (60,255,0) с текстурой скина и отражением окружения. Цвет машины задаётся в игре.

## Установка на ПК (SA-MP / CRMP)

1. Выберите стандартную машину, которую будете заменять, например `admiral.dff` / `admiral.txd`.
2. Переименуйте `exec_sedan.dff` → `admiral.dff`, а нужный скин, например `exec_sedan_police.txd`, → `admiral.txd`.
3. Положите файлы в `modloader/` или замените их в `models/gta3.img` через IMG Tool / Alci's IMG Editor.
4. Чтобы двигались руль, стрелки и поворотники, установите VehFuncs или ImVehFt. Без них машина работает, но эти узлы стоят на месте.

## Установка на мобильный CRMP (Android)

Мобильные клиенты (Black Russia‑подобные) обычно собраны по‑своему. Ниже общий порядок для клиентов на базе Android GTA SA:

1. `.dff` кладётся так же: замените модель в `gta3.img` (APK Editor / IMG Tool для Android) или в папку модлоадера клиента.
2. Текстуры: Android SA хранит их в базах `texdb`. Импортируйте `.txd` или PNG из `textures/` через TXD Tool в базу `gta3` под тем же именем модели.
3. Если у вас свой клиент, руль, стрелки и поворотники подключаются по именам узлов `f_steer`, `f_spdo`, `f_tach` и цветам материалов поворотников, перечисленным выше.
4. Для слабых телефонов можно пересобрать модели с текстурами 1024 вместо 2048: см. `size="lo"` в `tools/build.py`.

Модель весит около 60 тысяч треугольников вместе с салоном и _dam‑версиями. Видимых одновременно примерно 30–35 тысяч.

## Пересборка

```
pip install bpy pillow
cd tools
python -I build.py supercar ../build/supercar --renders
```

Пресеты машин лежат в `tools/presets.py`. Новая машина делается копированием пресета и правкой профилей: длина, крыша, линия окон, ширина, фары.

## Что не проверено

У автора генератора не было запущенной GTA. Структура файлов проверяется кодом (`rw.walk`), но первую машину стоит открыть в игре или в Kam's / DragonFF и проверить: коллизию, положение сидений (`ped_frontseat`) и handling. Строки для `handling.cfg` подбирайте от заменяемой машины.
