# Полигон 47

Браузерный шутер от первого лица на Three.js. Волны манекенов, АК-47 с отдачей, прицеливание по мушке, перезарядка с выниманием магазина и семь скинов, которые рисуются шейдером.

Запуск: откройте папку через любой локальный сервер (например `python3 -m http.server`) и зайдите на `http://localhost:8000/games/poligon47/`. Если открыть `index.html` напрямую как файл, модель не загрузится.

Управление: WASD — движение, мышь — обзор, ЛКМ — огонь, ПКМ — прицел, R — перезарядка, F — осмотр, Пробел — прыжок, C — присед, Shift — шагом. На телефоне есть сенсорные кнопки.
