# xmr-miner — учебный CPU-майнер в стиле Monero на xxhash

Пример того, как устроен CPU-майнер: блоб блока в формате Monero, перебор
4-байтового nonce (смещение 39), проверка сложности по правилу Monero
`hash_le * difficulty < 2^256`, параллельная работа на всех ядрах через
`multiprocessing`, подсчёт хешрейта и цепочка «найденных» блоков.

> **Важно:** в Monero используется Proof-of-Work **RandomX**, а не xxhash.
> Пул или сеть такие хеши не примут. Майнить XMR этот скрипт не будет,
> он только показывает, как устроен майнер.

## Запуск

```bash
pip install -r requirements.txt
python miner.py                     # все ядра, сложность 200000
python miner.py -t 4 -d 1000000     # 4 процесса, выше сложность
python miner.py --blocks 5          # остановиться после 5 блоков
```

| Флаг | Описание |
|------|----------|
| `-t/--threads` | число процессов-воркеров (по умолчанию все ядра) |
| `-d/--difficulty` | сложность: среднее число хешей на блок |
| `--blocks` | остановиться после N блоков (0 — без ограничения) |
| `--report` | интервал вывода хешрейта в секундах |

## Как сделать настоящий майнер

1. Заменить `pow_hash()` на RandomX (например, через Python-биндинги к
   librandomx) с seed hash из задания.
2. Получать задания (`blob`, `target`, `seed_hash`) от пула по протоколу
   Stratum (JSON-RPC поверх TCP: `login` → `job` → `submit`).

Под реальную добычу на Python этот путь всё равно медленный: на одном
ядре RandomX выдаёт порядка сотен H/s. Для настоящего майнинга берите
[XMRig](https://github.com/xmrig/xmrig) и майните только на своём
оборудовании.
