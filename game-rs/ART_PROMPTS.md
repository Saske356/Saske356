# Промты для новых моделей «Света Бездны»

Как пользоваться:
1. Открой ChatGPT (генерация картинок) и **первым сообщением** вставь блок «СТИЛЬ».
2. Дальше по одному промту из списка на сообщение: «Нарисуй: …».
3. Каждую картинку скачивай в PNG и называй **точно как в списке** (`boss1.png`, `pl_azure.png`…).
4. Если ChatGPT сделал фон не прозрачным — попроси: «Сделай фон прозрачным, ничего больше не меняй».
5. Присылай мне архивом или пачками по 5–10 штук — я нарежу, вставлю, оживлю (плавники, щупальца, челюсти).

Правила, без которых картинка не подойдёт:
- **Вид строго сбоку, существо смотрит ВПРАВО.**
- **Прозрачный фон**, без теней на земле, без рамок, без текста.
- Одно существо на картинку, по центру, занимает ~80% кадра, ничего не обрезано.
- Квадрат 1024×1024.
- У боссов **пасть приоткрыта** и видны зубы — я вырежу челюсть, и она будет двигаться.

## СТИЛЬ (вставить первым сообщением)

```
You are drawing game sprites for a mobile deep-sea arcade "Light of the Abyss".
Style for EVERY image in this chat:
- polished hand-painted 2D game art, like a premium mobile game (Ori / Hollow Knight level of finish),
  rich painterly shading, clean readable silhouette, crisp edges, subtle rim light;
- deep-sea bioluminescent creatures: glowing spots, translucent fins, glowing eyes;
- strong but harmonious colours, one main colour + one accent colour per creature, no rainbow mess;
- strict side view, the creature faces RIGHT;
- one creature, centered, fills ~80% of a square 1024x1024 canvas, nothing cropped;
- TRANSPARENT background (PNG with alpha), no ground, no shadow, no frame, no text, no watermark;
- same light direction in all images: soft light from top-left, rim light on the right edge.
Reply only with the image.
```
