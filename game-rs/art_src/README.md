# Исходники картинок (ChatGPT)

Оригиналы, из которых нарезаны спрайты 3.5. Сжаты в WebP.
Нарезка (нужны `rembg`, `onnxruntime`, `scipy`): положить файлы как `in/ИМЯ.png` в рабочую папку и запустить
`tools/proc.py` (вырезает фон) → `tools/export.py` (подгоняет размер, ярусы `_t1/_t2`, перекраски обликов)
→ `python3 tools/cut_jaw.py` из `game-rs` (челюсти боссов). Фоны: `tools/bg.py` (лист 5×3 → бесшовные плитки `assets/ground`).
